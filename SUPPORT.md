# Support

Oráculo is an early-stage open-source project maintained on a best-effort basis.

## Before asking for help

1. Read the [installation guide](docs/INSTALLATION.md) and [user guide](docs/USER-GUIDE.md).
2. Check [troubleshooting](docs/TROUBLESHOOTING.md).
3. Search existing Issues for the exact error.
4. Remove API keys, personal data, databases and private paths from logs.

## Where to ask

- Reproducible defect: use the Bug Report form.
- Product proposal: use the Feature Request form.
- Security vulnerability: follow [SECURITY.md](SECURITY.md), never a public Issue.
- General usage question: use GitHub Discussions after it is enabled.

Include operating system, Python and Node versions, installation method, expected behavior, actual behavior and minimal reproduction steps. Support cannot recover lost secrets, provide professional financial/legal/medical advice or guarantee compatibility with unlisted environments.
