# Oráculo Roadmap

This roadmap communicates direction, not a delivery promise. Priorities may change with evidence from real use and community feedback.

## v0.1 — Public foundation

- generic, idempotent DEMO seed;
- local-first FastAPI, SQLite and React application;
- structured decisions, evidence, hypotheses and predictions;
- deterministic comparison, optional AI analysis and red team;
- human confirmation, outcomes and calibration;
- safe configuration, backup and cross-platform documentation.

## Near term

- continuous integration for backend tests and frontend builds;
- smaller frontend bundles and route-level code splitting;
- improved accessibility and responsive behavior;
- import/export validation and documented restore testing;
- clearer onboarding for replacing DEMO data;
- screenshots and release artifacts.

## Exploration

- provider abstraction and local-model support;
- richer evidence provenance and source quality;
- Bayesian updating and scenario simulation;
- Monte Carlo analysis where inputs justify it;
- knowledge-graph improvements;
- optional encrypted local storage;
- opt-in multi-device or multi-user architectures.

## Guardrails

The roadmap does not include silent autonomous spending, messaging or irreversible actions. Any such capability requires explicit design review, scoped permissions, audit logs and human confirmation.
